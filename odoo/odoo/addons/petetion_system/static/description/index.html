📝 Petition Portal

Online Petition Submission System for Educational Institutions

Version 1.0 | LGPL-3 License

📋 Overview

The Petition Portal module allows students and staff to submit petitions online, such as course changes, leave requests, scholarship applications, or complaints. Administrators can review, approve, or reject petitions efficiently.

✨ Key Features

🌐

Public Web Form

Submit petitions through a responsive online form without authentication.

📄

Document Upload

Attach supporting documents for verification and processing.

🔄

Workflow Management

Track petitions from Draft → Submitted → Under Review → Approved/Rejected.

🎯

Petition Types

Supports course changes, leave requests, scholarships, and complaints.

🔍

Status Tracking

Users can monitor their petition status anytime using a reference number.

✅

Validation

Built-in checks ensure required fields, proper formats, and integrity of submissions.

🚀 Quick Start

Installation Steps:

  1. Copy the module to your Odoo addons directory
  2. Update your apps list in Odoo
  3. Install the "Petition Portal" module
  4. Configure petition types
  5. Start accepting petitions!
💡 Tip: Use the command make update-module MODULE=petition_portal to quickly install or update the module.

🎯 Use Cases

  • Universities & Colleges: Manage student petitions and requests
  • High Schools: Track leave, course change, and complaint petitions
  • Training Centers: Accept petitions for course adjustments
  • Professional Programs: Process scholarship or certification requests

📊 Petition Workflow

  1. Draft: Petition created but not yet submitted
  2. Submitted: Petition submitted by the user
  3. Under Review: Being evaluated by administrators
  4. Approved: Petition accepted
  5. Rejected: Petition declined

🔧 Technical Specifications

  • Odoo Version: 16.0+
  • Dependencies: base, web, website, petition_management
  • License: LGPL-3
