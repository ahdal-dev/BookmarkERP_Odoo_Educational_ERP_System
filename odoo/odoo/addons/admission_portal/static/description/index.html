🎓 Admission Portal

Online Admission Application System for Educational Institutions

Version 1.0 | LGPL-3 License

📋 Overview

The Admission Portal module transforms your Educational ERP into a complete admission management system. It enables prospective students to submit applications online while providing administrators with powerful tools to manage and process applications efficiently.

✨ Key Features

🌐

Public Web Form

Beautiful, responsive application form accessible to anyone without authentication.

📄

Document Upload

Upload transcripts and supporting documents for OCR processing and verification.

🔄

Workflow Management

Complete application lifecycle from Draft to Accepted/Rejected with status tracking.

🎯

Program Management

Define and manage academic programs with automatic application counting.

🔍

Status Tracking

Applicants can check their application status anytime using reference numbers.

✅

Validation

Built-in email format and GPA range validation for data integrity.

🚀 Quick Start

Installation Steps:

  1. Copy the module to your Odoo addons directory
  2. Update your apps list in Odoo
  3. Install the "Admission Portal" module
  4. Configure your academic programs
  5. Start accepting applications!
💡 Tip: Use the command make update-module MODULE=admission_portal to quickly install or update the module.

🎯 Use Cases

  • Universities & Colleges: Streamline undergraduate and graduate admissions
  • High Schools: Manage student enrollment applications
  • Training Centers: Accept course enrollments online
  • Professional Programs: Process certification program applications

📊 Application Workflow

  1. Draft: Initial state when application is created
  2. Submitted: Application submitted by applicant
  3. Under Review: Being reviewed by admissions team
  4. Accepted: Application approved
  5. Rejected: Application declined

🔧 Technical Specifications

  • Odoo Version: 16.0+
  • Dependencies: base, web, website, education_management
  • License: LGPL-3
  • Models: school.admission, school.program
  • Public Routes: /admission/apply, /admission/submit, /admission/thank_you
