Educational ERP Authentication & Authorization

A comprehensive authentication module for the Educational ERP system with role-based access control (RBAC) and custom dashboards.

Key Features

Role-Based Access Control

  • Student Group: Portal-based access to student dashboard
  • Admission Officer Group: Internal user with admission management access
  • ERP Admin Group: Full administrative access

Custom Login Experience

  • Student-friendly login page at /edu/login
  • Automatic post-login routing based on user role
  • Password visibility toggle
  • Links to admission application

Role-Specific Dashboards

  • /student/dashboard: Student portal with quick actions
  • /admission/dashboard: Admission statistics and management
  • /admin/dashboard: System overview and administration

Security Features

  • Route-level access control verification
  • Record rules for data access control
  • Session validation
  • 403 Forbidden handling for unauthorized access

Routes

Route Access Description
/edu/login Public Custom login page
/student/dashboard Students Student portal dashboard
/admission/dashboard Admission Officers Admission management dashboard
/admin/dashboard ERP Admins System administration dashboard
