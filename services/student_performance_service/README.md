# Student Performance Service

A small FastAPI service that predicts a student's academic trajectory from a transcript
summary. It serves the two models trained in
`notebooks/Student_Performance_Prediction.ipynb`:

- **GRU** (PyTorch) - next-semester GPA
- **XGBoost** - risk level (Low / Medium / High)

and adds rule-based alerts and recommendations.

## Layout

```
.
├── app/
│   ├── main.py        FastAPI app (/predict, /health)
│   ├── schemas.py     request / response models
│   ├── predictor.py   combined inference logic
│   ├── features.py    feature engineering from the summary
│   └── model.py       loads the trained artifacts
├── models/            generated by train.py (gitignored: *.pt, *.joblib)
├── train.py           trains both models from transcripts.json
├── input.json         example request body
├── requirements.txt
└── dockerfile
```

## 1. Train the models

The model files are not committed. Generate them once:

```bash
python train.py
# or point at a specific dataset:
python train.py ../../data/"Data Generation"/generated_data/transcripts.json
```

This writes `models/next_gpa_gru.pt` and `models/risk_xgboost.joblib`.

## 2. Run the API

```bash
uvicorn app.main:app --host 0.0.0.0 --port 5000
```

- Swagger UI: http://localhost:5000/docs
- Health check: http://localhost:5000/health

## 3. Call it

```bash
curl -X POST http://localhost:5000/predict \
     -H "Content-Type: application/json" \
     -d @input.json
```

### Request

```json
{
  "student_id": "STU-2021-0042",
  "transcript_summary": {
    "semester_gpas": [3.5, 3.2, 2.8, 2.6],
    "cumulative_gpa": 3.0,
    "total_credits_completed": 72,
    "total_credits_attempted": 78,
    "fail_withdrawal_count": 2,
    "academic_standing": "Good Standing",
    "domain_gpas": {"MATH": 2.9, "CS": 3.4, "HUM": 3.6}
  }
}
```

### Response

```json
{
  "student_id": "STU-2021-0042",
  "predictions": {
    "next_semester_gpa": 2.73,
    "predicted_graduation_gpa": 2.89,
    "trajectory": "Declining",
    "risk_level": "Low",
    "risk_score": 0.04
  },
  "alerts": [
    "GPA dropped 0.9 points over 4 semesters",
    "2 withdrawals/failures detected, possible course-load issue"
  ],
  "recommendations": [
    "Advising session recommended for MATH domain weakness",
    "Schedule early check-in with academic advisor on declining trend"
  ]
}
```

## Docker

Train the models first (so `models/` is populated), then:

```bash
docker build -t student-performance-service .
docker run -p 5000:5000 student-performance-service
```

## Notes

- `predicted_graduation_gpa` is a heuristic estimate (assumes a 120-credit programme),
  not a trained output.
- The models are trained on synthetic data; see the notebook's Limitations section.
